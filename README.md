# Chatixy AI Support Agent - Discourse theme component

Part of [Chatixy](https://chatixy.com). Adds the Chatixy AI support agent to a
Discourse forum with no code: install this component, paste your widget key in
its settings, and the one-line loader is injected on every page.

Docs and support: https://chatixy.com/integrations/discourse/

## Install (admin)

1. Go to **Admin -> Customize -> Themes**.
2. Click **Install -> From a git repository** and paste
   `https://github.com/Devoflex/discourse-chatixy`.
3. Open the component, go to **Settings**, paste your **Widget key**
   (Chatixy dashboard -> *Install*), and save.
4. Add the component to the theme(s) that should show the support agent.

Self-hosted Discourse can install any git theme component. Hosted plans may
restrict git installs to higher tiers; check your plan.
